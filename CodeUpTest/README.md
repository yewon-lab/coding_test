# CodeUpTest Project

This project contains a series of Python coding exercises, numbered from Q001.py to Q100.py. Each file is intended for individual coding problems that can be solved using Python.

## Structure

- **Q001.py to Q100.py**: These files are empty and are meant for you to implement solutions to the respective coding problems. You can fill each file with your code as you work through the exercises.

## Instructions

1. Clone or download this repository to your local machine.
2. Navigate to the `CodeUpTest` directory.
3. Open each QXXX.py file in your preferred code editor.
4. Solve the coding problems and implement your solutions in the corresponding files.
5. You can run your Python scripts to test your solutions.

Happy coding!
